# Practice Tracks

This directory now contains two separate PostgreSQL practice tracks:

- `custom_practice/`
  - Your original end-to-end practice set (basics to advanced interview-style progression).
- `postgres_docs_practice/`
  - A new track based on official PostgreSQL documentation concepts and examples converted into query questions.
- `postgres_non_select_practice/`
  - A non-SELECT-focused PostgreSQL track covering DDL/schema fundamentals, inheritance, partitioning, constraints, indexing, transactions, locks, system catalogs, data types, text search, functions/operators, security, extensions, and operations.

## Suggested Order

1. Finish `custom_practice/` for broad SQL muscle.
2. Use `postgres_docs_practice/` to deepen PostgreSQL-specific query features and behavior.
3. Use `postgres_non_select_practice/` for schema, operational, and advanced platform concepts.

## Coverage Notes

- `postgres_non_select_practice/15_docs_index_tutorial_coverage_matrix.md` maps practice coverage to the PostgreSQL docs index/tutorial structure.
- `postgres_non_select_practice/16_non_select_completion_checklist.md` is the completion gate for non-SELECT fundamentals through operations.
