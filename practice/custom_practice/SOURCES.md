# Sources and Inspiration

This practice set is original content, but question styles and progression were inspired by common SQL learning/interview sources:

- PostgreSQL Exercises (PGExercises):
  - https://pgexercises.com/questions/basic/
- HackerRank SQL domain:
  - https://www.hackerrank.com/domains/sql
- SQLBolt tutorial track:
  - https://sqlbolt.com/
- SQLZoo beginner exercises:
  - https://sqlzoo.net/wiki/SELECT_basics
- DataLemur SQL interview problem style:
  - https://datalemur.com/questions
- LeetCode Database problem-set style (SQL 50 / interview style):
  - https://leetcode.com/problemset/database/
- W3Resource SQL exercises catalog:
  - https://www.w3resource.com/sql-exercises/

Notes:
- Direct extraction from some platforms can be blocked by anti-bot protections (for example, LeetCode may return 403 without an authenticated browser session).
- This repository practice pack adapts broad themes (filtering, joins, windows, recursion, analytics) into one PostgreSQL dataset so progression is smooth from beginner to advanced.
