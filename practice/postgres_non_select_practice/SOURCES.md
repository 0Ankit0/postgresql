# Sources

This track is built from PostgreSQL official documentation topics beyond plain SELECT practice.

Primary docs index:
- https://www.postgresql.org/docs/current/index.html

Primary tutorial and index anchors:
- https://www.postgresql.org/docs/current/tutorial.html
- https://www.postgresql.org/docs/current/bookindex.html

Referenced topic groups include:
- DDL fundamentals (create/alter/drop) and schema/search_path behavior
- DDL and schema design (inheritance, partitioning, constraints)
- Indexes and planner-oriented access path design
- Transactions, MVCC, explicit locking, and isolation
- Views/materialized views/rule system
- Functions, procedures, triggers, PL/pgSQL
- System catalogs and information_schema introspection
- Data types, casts, domains, and type-system design
- Full text search workflow and indexing
- Roles/privileges and row-level security
- Types, sequences, extensions, FDW
- Maintenance and monitoring

Note:
- Tasks are original practice prompts inspired by documentation concepts.
